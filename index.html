ในขณะที่เปิดเว็บไซต์จากเครื่องของตนเอง มี client หรือ server เกิดขึ้นแล้วหรือไม่ เพราะเหตุใด

ในขณะที่เปิดเว็บไซต์จากเครื่องตัวเอง Web Browser จะทำหน้าที่เป็น Client แต่จะยังไม่มี Server เกิดขึ้น เพราะยังไม่มีการใช้ Protocol HTTP หรือเครือข่ายในการร้องขอข้อมูล(Request/Response)

How I Built It

ขั้นตอนการพัฒนา

  1. สร้าง folder A1project7869
  2. สร้าง index.html และ style.css
  3. สร้าง folder css และ media เพื่อความเป็นระเบียบ
  4. เขียน content ลงบน index.html(ใช้ link ในการเชื่อม index.html กับ style.css)
  5. เพิ่มรูปใส่โฟลเดอร์ media และใส่ Relative Path ใน index.html
  6. ตกแต่งเว็บไซต์ผ่าน style.css
  7. ลองทดสอบเปิดเว็บไซต์ และ แก้ไขปรับปรุงข้อผิดพลาด

เครื่องมือหรือแหล่งเรียนรู้ที่ใช้

  • google
  • สไลด์ CS100 Module 02-03 Basic HTML & CSS
  • gemini(ใช้เพื่อถามคำถามที่ยังไม่เข้าใจ)
  • visual studio code

Reflection

ปัญหาหรือความท้าทายที่พบ และรับมืออย่างไร

ปัญหาที่พบคือ ผมไม่เก่งเรื่องการตกแต่งเว็บไซต์ และวิธีรับมือคือ ลองเสริช์หาไอเดียของเว็บไซต์ต่างๆ

จากการทำ A1 เข้าใจอะไรเกี่ยวกับการพัฒนาเว็บไซต์มากขึ้น

เข้าในหลักการทำงานของเว็บไชต์มากขึ้น และเข้าใจระเบียบวิธีการทำงานของนักพัฒนาเว็บไชต์

หากได้พัฒนางานนี้ต่อ อยากปรับปรุงหรือเพิ่มเติมอะไร และเพราะอะไร

อยากพิมพ์ให้ไวขึ้น เพราะรู้สึกว่าถ้าพิมพ์ช้าจะทำให้ใช้เวลาเยอะมาก และอยากเพิ่มไอเดียของการตกแต่ง เพราะจะนำไปต่อยอดใช้ในอนาคตต่อไป
